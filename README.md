# TechBridge

Plataforma desenvolvida para integração e gerenciamento de serviços tecnológicos.

## Tecnologias
- Java
- Spring Boot
- SQL
- Git/GitHub

## Funcionalidades
- Cadastro de usuários
- Gerenciamento de solicitações
- Integração entre módulos
- Persistência em banco de dados

## Objetivo
Projeto desenvolvido para praticar arquitetura backend, lógica de negócios e integração de sistemas.
